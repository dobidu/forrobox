<objective>
## Goal
**CMake** (inside `if (APPLE)` where needed):
- `FORMATS` gains `AU` on Apple. Linux and Windows are unchanged.
- `CMAKE_OSX_ARCHITECTURES "arm64;x86_64"` and `CMAKE_OSX_DEPLOYMENT_TARGET 11.0`, set before
  `project()`. Universal, macOS 11 floor (the user's choice).
- The AU needs `AU_MAIN_TYPE kAudioUnitType_MusicDevice` (it is an instrument), and its
  manufacturer and subtype come from the existing `Frbx` codes.

**`scripts/build-macos.sh`:**
1. Configure Xcode or Ninja, then build Release: `ForroBox_VST3`, `ForroBox_AU`,
   `ForroBox_Standalone`, `ForroBoxTests`.
2. **Ad-hoc sign** the three bundles with `codesign --force --deep -s -`. Apple Silicon refuses to
   load unsigned code. Then verify with `codesign --verify --deep --strict`.
3. **Universal check:** `lipo -archs` on each binary reports `x86_64 arm64`.
4. **`auval`:** copy the `.component` to `~/Library/Audio/Plug-Ins/Components`, kill
   `AudioComponentRegistrar` so it rescans, then run `auval -v aumu Frbx Frbx`. It must end
   "AU VALIDATION SUCCEEDED".
5. `scripts/validate-plugin.sh --macos <vst3>`.
6. **The FULL suite** (`ForroBoxTests`), judged by its result line.

**`validate-plugin.sh --macos`:**
- the macOS zip is pinned by version and hash (`pluginval_macOS.zip`, v1.0.4, sha256
  `3c4c533bda0c5059eea3ddaea752d757ee2025041f0f47e6bcb0e87f6082b29f`, first downloaded
  2026-10-04);
- it runs `pluginval.app/Contents/MacOS/pluginval`;
- hashing is portable (`sha256sum`, else `shasum -a 256`);
- the bash-4 features it uses (`declare -A`) need a bash ≥ 4. Make that explicit: the CI step
  runs it under Homebrew's bash, or the arrays are replaced with a `case`, whichever is smaller.

**`ci.yml`:** a `macos` job (`macos-14`, Apple Silicon) on push, PR and tag that runs
`scripts/build-macos.sh`.

**The user's choice: the full suite must pass on macOS.** Every failure is investigated:
- a real macOS bug is fixed in `src/`;
- a check whose threshold depends on the renderer gets a principled, per-platform tolerance;
- each tolerance is recorded in the SUMMARY with the measured value and why. None is loosened
  globally, and none is skipped.
- There is no local Mac. Iteration happens on CI, one small commit per finding.

## Purpose
- **ROADMAP Phase 17:** "VST3 + AU, universal binary, on a GitHub Actions macOS runner; validated
  there by `auval`, pluginval and the suite".
</objective>
