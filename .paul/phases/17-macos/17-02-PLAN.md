<objective>
## Goal
**`package-release.py --platform macos`** writes `ForroBox-<version>-macos-universal.zip` with one
top folder holding:
- `ForroBox.component`, `ForroBox.vst3` and `ForroBox.app`, copied whole with their
  `_CodeSignature`;
- `LICENSE`, `ABOUT.md`, `NOTICE.md`, `INSTALL.txt` and `licenses/`.

The script generalises from "one bundle + one standalone file" to a per-platform list of bundles.
The Linux and Windows layouts stay byte-for-byte what 16-01 produces.

**macOS specifics:**
- Every Mach-O file under a bundle's `Contents/MacOS/` keeps mode 0755.
- A symlink in a bundle is refused unless the zip stores it as a symlink. Check what JUCE emits;
  `.app`/`.component`/`.vst3` from JUCE normally contain none.
- The version check reads the VST3's moduleinfo (as now) and also the AU's and app's `Info.plist`
  `CFBundleShortVersionString`, so all three bundles must equal `CMakeLists.txt`'s version.

**`packaging/INSTALL-macos.txt.in`:**
- macOS 11+, universal (Apple Silicon and Intel).
- Install paths: `~/Library/Audio/Plug-Ins/Components/` (AU), `~/Library/Audio/Plug-Ins/VST3/`,
  `/Applications/` (app).
- **Gatekeeper:** the bundles are ad-hoc signed, not notarised (no Apple developer account), so
  macOS quarantines a download. Lift it with
  `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/ForroBox.component` (and
  likewise for the others), or Control-click → Open for the app. Then rescan in the host. It is
  listed as "Forro Box".

**CI:**
- **The `macos` job**, on a tag, after `build-macos.sh`:
  1. `package-release.py --platform macos --artefacts build-macos/ForroBox_artefacts/Release
     --out dist`.
  2. **Prove the zip:** unzip into a temp dir, then run `codesign --verify --deep --strict` and
     `lipo -archs` on each unzipped bundle. A zip that broke a signature would make the AU fail to
     load on Apple Silicon.
  3. Upload `package-macos`.
- **The `release` job** `needs` `macos` too, and attaches `ForroBox-*-macos-universal.zip`.
  `SHA256SUMS.txt` then covers all three archives.

## Purpose
- **ROADMAP Phase 17:** "packaged unsigned with Gatekeeper notes", plus 16-03's release job, now
  with three platforms.
