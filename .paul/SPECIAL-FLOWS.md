## Project-Level Dependencies

Skills and commands that apply to this project's work.

| Work Type | Skill/Command | Priority | When Required | Notes |
|-----------|---------------|----------|---------------|-------|
| Audio-thread / DSP / processor code | `/code-review` | required | After every APPLY that touches `PluginProcessor`, voices, the sequencer clock, or APVTS state | Focus: no allocation or locks in the audio callback, sample-accurate step timing, host-sync/PPQ alignment, state round-trip |
| Spec and codebase lookup | `/graphify` | required | Before planning a phase, and whenever a question needs an answer out of `PLANNING.md` or the prototype sources | Avoids re-reading the 46 KB handoff and 95 KB of prototype JS by hand |
| GUI fidelity vs. the prototype | `/impeccable` | optional | When building or critiquing the JUCE chassis, Knob, step pads, or either theme | Web-oriented skill — use for design critique and hierarchy/contrast checks against the prototype, not for generating C++ |
| Quality cleanup before closing a phase | `/simplify` | required | During UNIFY, before marking a phase complete | Reuse/simplification/efficiency only; it does not hunt bugs — that is `/code-review` |

**Priority Legend:**
- `required` - Gap documented if not invoked during UNIFY
- `optional` - Informational only, no gap logged
