<objective>
## Goal
Three deferrals from 13-02's /simplify, all about one seam:

1. **One owner for the global font.**
   - Today each `Chassis` writes `type::setMonoFamily` through `applyTo`, and the one that changes
     it re-announces with a public `Settings::notifyListeners()`.
   - After: the STORE sets the family, once, before it notifies. That happens in
     `Settings::notify (const Snapshot&)`, which is private. `applyTo` touches only the instance's
     LookAndFeel.
   - The seed path gets `Settings::seedSnapshot()`. It reads the file, and if the file's family
     differs from the process's, it publishes to every listener. The open instances hear another
     process's font choice through the same single path.
2. **A snapshot handed to listeners.**
   - `Listener::settingsChanged (const Snapshot&)`. After a write, `set` builds the snapshot from
     the values it just wrote, with no re-read.
   - N open instances then cost 0 extra parses per change, not N.
3. **A test for the top-level repaint.**
   - A recording `juce::CachedComponentImage` on an editor proves that a theme change from ANOTHER
     instance invalidates the editor itself (letterbox and tooltip), not just the chassis.
   - This works headless: `Component::internalRepaintUnchecked` calls `cachedImage->invalidate…`
     with no peer.

Also, **closed as won't-do at Phase 14 planning, by the user**, recorded in STATE and in the summary:
- the pulse's timer stays independent of the sway's;
- the `resized()` walk stays, over `lookAndFeelChanged`.
