<objective>
## Goal
- **CMakeLists.txt:** set `CMAKE_MSVC_RUNTIME_LIBRARY` to `MultiThreaded$<$<CONFIG:Debug>:Debug>`,
  guarded by `MSVC`, before any target is created.
  - CMP0091 is NEW under `cmake_minimum_required (3.22)`.
  - Every target then links the static CRT and C++ runtime (`/MT`, `/MTd`): `ForroBox`, its VST3
    and Standalone wrappers, `ForroBoxTests`, and JUCE's modules compiled into them.
- **scripts/build-windows.sh:** after the build, check the PE imports of every binary it ships or
  runs (the VST3 module, `ForroBox.exe`, `ForroBoxTests.exe`) with `objdump -p`.
  - It FAILS, naming the binary and the DLL, if any imports `VCRUNTIME*.dll`, `MSVCP*.dll` or
    `vcruntime*`/`concrt*`/`api-ms-win-crt-*`.
  - Checked: `objdump` reads PE `DLL Name:` entries on this machine; today's standalone imports
    `MSVCP140.dll`.
  - `api-ms-win-crt-*` is the UCRT forwarders. These must also vanish: `/MT` links the UCRT
    statically too, which is what makes the package redistributable-free.
- **README.md:** the Windows requirement line drops the redistributable.

## Purpose
- **ROADMAP Phase 15:** "Windows: static MSVC runtime — no VC++ 2015–2022 Redistributable needed".
- **The v0.1 release deferral:** the Windows build links the MSVC runtime DYNAMICALLY.
- **Phase 16's CI** builds exactly this configuration, so the check belongs in the build itself,
  not in a release checklist.
</objective>
