<objective>
## Goal
**The user's choice at Phase 15 planning:** the floor is Ubuntu 22.04 / glibc 2.35. That covers
Ubuntu 22.04+, Debian 12+, Fedora 36+ and Mint 21+.

- **`docker/linux-portable.Dockerfile`:** Ubuntu 22.04, plus:
  - `gcc-13`/`g++-13` from `ppa:ubuntu-toolchain-r/test`;
  - CMake (22.04 ships 3.22.1, which meets `cmake_minimum_required (3.22)`) and Ninja;
  - Python 3, and Node 20 LTS from the official nodejs.org tarball, pinned by SHA256. The build's
    two cross-check gates need Python 3 and Node 18+, and 22.04's own Node is 12;
  - JUCE's Linux dev packages: ALSA, FreeType, fontconfig, X11 and its extensions, with web
    browser and curl off as they already are;
  - `xvfb`, for the GUI tests.
- **`CMakeLists.txt`:** `option (FORROBOX_PORTABLE_LINUX OFF)`. When ON, it adds
  `-static-libstdc++ -static-libgcc` to the link of the VST3 and Standalone wrappers and of
  `ForroBoxTests`.
  - With those two static, the binaries' only versioned dependency is glibc, at 2.35.
- **`scripts/build-linux-portable.sh`:**
  1. Build the image, cached.
  2. Configure and build Release in it, into `build-portable/`, with the repo mounted and
     `~/JUCE` mounted READ-ONLY as `JUCE_PATH`.
  3. **Floor check** on the VST3 `.so`, the standalone and the test binary:
     - the highest `GLIBC_` symbol version is ≤ 2.35;
     - there is no `GLIBCXX_`/`CXXABI_` version at all, because libstdc++ is static;
     - FATAL with the offending symbol otherwise.
  4. **Clean-machine run:** a FRESH `ubuntu:22.04` container with only runtime libraries (no
     compiler, no GCC 13 libstdc++) runs:
     - `ldd` on the `.so` and the standalone, with no "not found" allowed;
     - the test suite under `xvfb-run`.

## Purpose
- **ROADMAP Phase 15:** "Linux: an older glibc / libstdc++ floor — built in a container, so Ubuntu

- **Phase 16's CI** runs this same container build, so it must be scripted, not described.
