- **09-09: MIDI input.** The plugin has declared `wantsMidiInput=true` since Phase 1 and thrown
  every note away at `processBlock`'s `midi.clear()`. It now reads the buffer before clearing it: a
  note on the GM percussion map sounds its lane, at the velocity sent, layered over the sequencer,
  gated by the same mute and solo the grid obeys, and never echoed back to the host that sent it.

## Blockers and Traps

**`scripts/build-windows.sh --install` had never worked, and the reason is instructive.**
`ForroBoxTests.exe` prints its full result and then never exits. `run()` buffers output to a temp
file and tees it only after the command returns — so the summary line did not even reach the log
until the process died, and the script never reached its install step. Killing the binary by hand
makes `run()` fail and the script exit `FATAL: 1 of 1 test executables failed under MSVC`, which is
the same dead end from the other side. Fixed at `b55135e`: the binary runs under a 900 s timeout and
is judged by the summary line it printed, with a hang that printed nothing — or printed FAILURES —
still counting as a failure.

**Read the real exit code from the log, never a wrapper's.** This session the task harness reported
"exit code 0" for a run whose log said `wrapper exit=1`. This is a standing project law and it bit
again.

**The allocation counter does not see `std::malloc`.** It replaces global `operator new` only
(`tests/ClockTest.cpp:37`), and JUCE uses `std::malloc` directly in at least `MidiMessage`. Any
future "allocation-free" claim on a path touching JUCE's own containers must say which of the two it
actually measured. One 09-09 fix shipped with no failing mutation for exactly this reason, and the
summary says so rather than showing a green check that means nothing.

**Any new trigger source must add `lookaheadSamples`.** There are three now — the grid, the ghost
roll and MIDI input — and the third got it wrong. A trigger that skips it is not merely early: it is
early by exactly the figure the plugin reports to the host, so the host's own compensation doubles
the error rather than hiding it.
