## Traps and Standing Laws

- **Read the real exit code from the log, never a wrapper's.**
- **A check that cannot fail proves nothing.** Every new instrument or gate is proven by a mutation
  it must reject. 10-02's own importlib detection was wrong, and only its must-reject self-test
  showed it.
- **`ninja -n` can't show gate re-runs** in these trees: `CONFIGURE_DEPENDS` globs make the glob
  check always dirty, so a dry run stops at "Re-running CMake". Prove re-runs with real builds or
  `ninja -t query <stamp>`.
- **Environment reaches a Windows process from WSL only via `WSLENV`.**
- **New gates:** call `gate_inputs.declare(__name__, files=…, globs=…)` just above the `__main__`
  guard, and end with `sys.exit(gate_inputs.run(main))`.
- Any new trigger source must add `lookaheadSamples`. The allocation counter doesn't see
  `std::malloc`.
